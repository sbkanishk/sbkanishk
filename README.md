A FastAPI backend + web frontend that lets users schedule technical or non-technical interviews with a human expert or an AI interviewer — includes resume building, ATS scanning, and LinkedIn optimization tools.

**[Game of Thrones Reference Site](https://github.com/sbkanishk/Game-of-Thrones)**
An interactive Game of Thrones reference website built with vanilla HTML/CSS/JS and deployed via GitHub Pages.
